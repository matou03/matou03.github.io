# C程序数据类型
咱们可以把 **C语言的数据类型** 想象成 **不同规格的储物容器**，用来存放各种数据。就像你存水用水杯、存书用书包一样，不同的数据类型对应不同的存储需求和大小

---

## 📦 **数据类型——数据的「房子」**
**作用**：决定数据在内存中占多大空间，能表示什么范围的数值。

---

## 🗂️ **四大类「房子户型」**
1. **基本类型（单身公寓）**  
   - **整型**：存整数 → `int`（标准间）、`short`（小单间）、`long`（大平层）  
   - **字符型**：存单个字符 → `char`（迷你仓，其实也是小整数）  
   - **浮点型**：存小数 → `float`（普通水杯）、`double`（大桶水）  
   - **例子**：  
     ```c
     int 年龄 = 25;          // 整型：存年龄
     float 体重 = 65.5f;     // 浮点：存体重（带f表示float）
     char 等级 = 'A';        // 字符：存成绩等级
     ```

2. **枚举类型（VIP专属房）**  
   - 只能存放预设的整数值（比如星期几、方向）  
   - **例子**：  
     ```c
     enum Week { Mon=1, Tue, Wed }; // 定义枚举
     enum Week 今天 = Wed;           // 今天=3
     ```

3. **void类型（隐形房）**  
   - **三副面孔**：  
     - 函数不返回值 → `void 吃饭() { ... }`  
     - 函数不需要参数 → `int 随机数(void) { ... }`  
     - 万能指针（像万能钥匙，但要指定类型后才能用） → `void* 神秘地址;`  

4. **派生类型（组合别墅）**  
   - 后续章节解锁：数组（一排连号房）、指针（门牌号）、结构体（套房）  

---

### 🔢 **整型「房型对比表」**
| 类型          | 存储空间  | 值范围（64位系统）      | 生活类比         |
|---------------|----------|------------------------|------------------|
| `char`        | 1字节    | -128~127 或 0~255      | 小抽屉（存年龄） |
| `unsigned int`| 4字节    | 0~4,294,967,295       | 超大储物箱       |
| `long`        | 8字节    | -9万亿~9万亿          | 仓库             |

**📢 关键技巧**  
- 选类型就像选背包：**够用就行**，别浪费空间  
   ```c
   unsigned short 学生人数 = 300;  // ✅ 0~65535足够
   short 温度 = -30;              // ✅ 有符号存负数
   ```

---

### 🌊 **浮点型「精度段位」**
| 类型          | 存储空间 | 精度         | 适用场景           |
|---------------|---------|-------------|--------------------|
| `float`       | 4字节   | 6~7位小数    | 日常测量（如体重） |
| `double`      | 8字节   | 15~16位小数  | 科学计算           |
| `long double` | 16字节  | 19位小数     | 超高精度需求       |

**🌰 例子**  
```c
double 圆周率 = 3.141592653589793; // 高精度
float 身高 = 1.75f;                // 普通精度
```

---

### 🚧 **避坑指南**
1. **整数溢出** → 像水杯装满还硬倒：  
   ```c
   char 小杯子 = 128; // ❌ char范围-128~127，128溢出成-128
   ```

2. **浮点精度陷阱** → 别用`==`直接比较：  
   ```c
   float a = 0.1 + 0.2;
   if (a == 0.3) { ... } // ❌ 可能失败！应用范围判断
   ```

3. **忘记加`f`后缀** → 默认是double：  
   ```c
   float 价格 = 9.99;   // ❌ 9.99默认是double，转float可能丢失精度
   float 正确价 = 9.99f; // ✅ 加f明确是float
   ```

---

### 🔍 **查看「房子」大小（sizeof神器）**
```c
#include <stdio.h>
int main() {
    printf("int大小: %zu字节\n", sizeof(int));      // 输出4（64位系统）
    printf("double大小: %zu字节\n", sizeof(double)); // 输出8
    return 0;
}
```

---

### 💡 **类型选择口诀**
> 整型看范围，浮点看精度，  
> 日常用int/double，省心又省力。  
> 超大数字上long，负号别忘记，  
> 字符本质是整数，存字母很容易！

## 🔄 **类型转换——数据的「变形记」**
**作用**：让不同类型的数据能一起工作，但要注意可能发生的数据丢失（像倒水时洒出来）。

---

### 🕵️♂️ **两种转换方式**
1. **隐式转换（自动倒水）**  
   - **规则**：从小杯转大杯（系统自动帮你完成）  
   - **例子**：  
     ```c
     int 小杯子 = 100;        // 整型（4字节）
     float 中杯子 = 3.14f;    // 浮点（4字节）
     double 大桶 = 小杯子 + 中杯子; // ✅ 自动转成double计算（8字节）
     ```
   - **风险**：大杯转小杯可能溢出（但系统不会提醒你）  
     ```c
     int 瓶子 = 3.14; // ✅ 合法，但会截断成3（像只留整数部分的水量）
     ```

2. **显式转换（手动切割）**  
   - **规则**：强制转换类型（像用模具切出指定形状）  
   - **语法**：`(目标类型)数据`  
   - **例子**：  
     ```c
     double 精准身高 = 175.8;
     int 大致身高 = (int)精准身高; // ✅ 砍掉小数，变成175
     ```
   - **风险**：数据可能被截断或失真  
     ```c
     char 小瓶 = (char)300; // ❌ char最大255，300转成44（溢出像水溢出杯子）
     ```

---

### 🌰 **生活场景对比**
| **场景**               | **隐式转换**                          | **显式转换**                          |
|-------------------------|--------------------------------------|---------------------------------------|
| **混合计算**           | `int + float` 自动转`float`          | 无                                    |
| **精确控制结果类型**   | 无                                   | `double 价格 = (int)9.99 + 1; // 10` |
| **处理函数参数类型**   | `sqrt(25)` 自动把int转double         | `sqrt((double)25)`                   |

---

### 🚧 **避坑指南**
1. **浮点转整型丢失精度**  
   ```c
   float 温度 = 36.6f;
   int 近似温度 = 温度; // 隐式转成36（直接砍掉小数，不是四舍五入！）
   ```

2. **大类型转小类型溢出**  
   ```c
   long 大数字 = 2147483648L; // 假设long是8字节
   int 小存储 = (int)大数字;   // ❌ 溢出成-2147483648（像大桶水灌炸小瓶）
   ```

3. **无符号和有符号混用**  
   ```c
   unsigned int 库存 = 10;
   int 销售量 = 50;
   if (销售量 > 库存) { ... } // ✅ 隐式转无符号，可能导致逻辑错误！
   ```

---

### 💡 **类型转换口诀**
> 隐式转换系统帮，小杯转大杯无痕。  
> 显式转换需手动，砍头去尾要谨慎。  
> 浮点转整丢小数，大数化小会失真。  
> 混用类型先统一，避免暗坑代码稳。

**附：测试你理解的灵魂三问** 🧐  
1. `(int)3.99`等于多少？ → **3**（直接砍掉小数）  
2. `char c = 1.5 + 2.7;`中c的值？ → **4**（隐式转int=4，再转char）  
3. `int a = 5; double b = a/2;`b的值？ → **2.0**（先做整数除法5/2=2，再转double）  
   **修正方法**：`double b = (double)a/2;` → 得到2.5
