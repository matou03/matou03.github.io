# C程序变量
---

## 一、变量是什么？——「数据的快递盒」
想象你有一个快递盒，这个盒子有 **三个重要信息**：
1. **盒子名字**（变量名）：比如「年龄盒」、「温度盒」
2. **盒子类型**（数据类型）：决定能放什么（只能放数字？放小数？放文字？）
3. **盒子里装的东西**（变量的值）：比如数字25、温度36.5

**示例**：
```c
int age = 25; // 创建一个叫age的整数盒，放数字25
float temperature = 36.5f; // 温度盒，放小数36.5
char grade = 'A'; // 等级盒，放字母A
```

---

## 二、变量的定义——「买快递盒」
**步骤**：告诉计算机你要什么类型、什么名字的盒子  
**语法**：`数据类型 变量名;`  
**重点**：  
- **数据类型**：就像盒子材质，决定能装什么（比如 `int` 盒子只能装整数）  
- **变量名**：盒子的标签，必须遵守起名规则（字母/下划线开头，不含空格和特殊符号）  

**正确例子**：
```c
int student_age; // 整数盒，名字是student_age
float _price;    // 小数盒，名字是_price（下划线开头）
```

**错误例子**：
```c
int 3students; // ❌ 数字开头
float price$;  // ❌ 包含特殊符号$
```

---

## 三、变量的赋值——「往盒子里放东西」
**两种方式**：
1. **定义时直接放**（初始化）：
   ```c
   int age = 18; // 创建age盒，直接放18
   ```
2. **先买盒子，后放东西**：
   ```c
   int age;      // 先买盒子（此时盒子里可能有垃圾）
   age = 18;     // 再往盒子里放18
   ```

**⚠️ 警告**：  
- **局部变量**（在函数内部定义的盒子）如果没放东西，打开时会看到**随机垃圾值**（可能引发bug！）  
  ```c
  void test() {
      int x; // 没初始化
      printf("%d", x); // ❌ 输出的是随机数！
  }
  ```

---

## 四、变量的类型——「盒子的种类」
C语言常用的「盒子类型」：

| 类型        | 能装什么         | 例子               | 备注                    |
|-------------|------------------|--------------------|-------------------------|
| `int`       | 整数             | `int age = 20;`    | 不带小数                |
| `float`     | 小数（精度低）   | `float pi = 3.14f;`| 末尾加`f`               |
| `double`    | 小数（精度高）   | `double pi = 3.1415926;` | 默认小数类型 |
| `char`      | 单个字符         | `char c = 'A';`    | 用单引号包裹            |

**特殊类型**：
- `void`：空盒子（不能装东西，用于特殊场合如函数返回值）  
- 其他复杂类型（数组、指针等）：后面章节解锁  

---

## 五、变量的作用域——「盒子在哪里能用？」
### 1. **全局变量**：整个程序都能用的「公共快递柜」
- **定义位置**：函数外面  
- **特点**：默认初始化为0  
  ```c
  #include <stdio.h>
  
  int global = 100; // 全局变量，所有函数都能用
  
  void test() {
      printf("%d", global); // ✅ 输出100
  }
  
  int main() {
      test();
      return 0;
  }
  ```

### 2. **局部变量**：只能在某个函数里用的「私人快递盒」
- **定义位置**：函数内部  
- **特点**：不初始化会含垃圾值，函数结束后盒子销毁  
  ```c
  void test() {
      int local = 50; // 局部变量
      printf("%d", local); // ✅ 输出50
  }
  
  int main() {
      printf("%d", local); // ❌ 错误！main函数不认识local
      return 0;
  }
  ```

---

## 六、变量的声明 vs 定义——「快递单 vs 真实包裹」
### 1. **声明**（Declaration）：告诉别人「这个盒子存在」
- **语法**：`extern 数据类型 变量名;`  
- **作用**：跨文件使用其他地方的变量（像借用别人的盒子）  
  ```c
  // file1.c
  int global = 100; // 真实盒子
  
  // file2.c
  extern int global; // 声明：global盒子在别处
  printf("%d", global); // ✅ 输出100
  ```

### 2. **定义**（Definition）：实际创建盒子
- **语法**：`数据类型 变量名;`  
- **特点**：分配内存空间  

---

## 七、左值 vs 右值——「盒子本身 vs 盒子里的东西」
### 1. **左值（Lvalue）**：能放在赋值左边的表达式  
- **特点**：有明确的内存位置（像快递盒本身）  
- **例子**：变量、数组元素  
  ```c
  int a = 10; // a是左值
  a = 20;     // ✅ 正确：修改盒子的内容
  ```

### 2. **右值（Rvalue）**：只能放在赋值右边的表达式  
- **特点**：临时值（像盒子里的物品）  
- **例子**：数字、计算结果  
  ```c
  int b = a + 5; // (a+5)是右值
  10 = a;        // ❌ 错误！不能给数字10赋值
  ```

## 八、常见错误 & 调试技巧
### 1. **变量名拼写错误**
```c
int studentAge = 20;
printf("%d", studentage); // ❌ 大小写错误！
```

### 2. **使用未初始化的局部变量**
```c
int x;
printf("%d", x); // ❌ x是随机值！
```

### 3. **类型不匹配**
```c
int a = 3.14; // ❌ 小数强制转整数（实际存3）
float b = 10; // ✅ 整数转小数（自动转成10.0）
```

### 4. **作用域错误**
```c
void func1() {
    int x = 5;
}

void func2() {
    printf("%d", x); // ❌ x只在func1里有效
}
```

   ```c
   int 1st_place = 100;

   ```

   **答案**：  
   ```c

   ```

2. **题目2**：以下代码输出什么？  
   ```c
   #include <stdio.h>
   int global;
   int main() {
       int local;
       printf("global=%d, local=%d", global, local);
       return 0;
   }
   ```

   **答案**：  
   `global=0`（全局变量默认0），`local`的值不确定（随机垃圾值）
