# 🚦 **C语言判断结构——程序中的「红绿灯」**  
判断结构让程序像交通信号灯一样，根据不同条件决定执行哪段代码。就像“红灯停🚦，绿灯行🚗”，程序也需要根据条件做出选择！

---

## 一、**if 语句——单条件检查**  
**作用**：如果条件成立，就执行代码块  
**语法**：  
```c
if(条件) {
    // 条件为真时执行
}
```

**生活例子**：  
```c
int 下雨 = 1; // 1表示下雨
if(下雨) {
    printf("带伞☔"); 
}
```

---

## 二、**if-else 语句——二选一**  
**作用**：条件成立执行A，否则执行B  
**语法**：  
```c
if(条件) {
    // 条件为真执行
} else {
    // 条件为假执行
}
```

**生活例子**：  
```c
int 温度 = 28;
if(温度 > 30) {
    printf("开空调❄️");
} else {
    printf("吹风扇💨"); 
}
```

---

## 三、**嵌套 if——多层条件筛选**  
**作用**：在条件内部再判断（像闯关游戏🎮）  
**语法**：  
```c
if(条件1) {
    if(条件2) { 
        // 条件1和2都满足
    }
}
```

**生活例子**：  
```c
int 年龄 = 18;
int 身高 = 175;
if(年龄 >= 18) {
    if(身高 >= 170) {
        printf("可以玩过山车🎢"); 
    }
}
```

---

## 四、**switch 语句——多选一开关**  
**作用**：根据变量值选择不同分支  
**语法**：  
```c
switch(变量) {
    case 值1: 代码; break;
    case 值2: 代码; break;
    default: 默认代码;
}
```

**生活例子**：  
```c
int 菜单选项 = 2;
switch(菜单选项) {
    case 1: printf("汉堡🍔"); break;
    case 2: printf("披萨🍕"); break;
    default: printf("暂无选项");
}
```

**⚠️ 注意**：  
- 每个`case`后要加`break`，否则会继续执行下一个case（称为“穿透”）  
- `default`是可选的，处理未匹配的情况  

---

## 五、**三元运算符 ? : ——快捷判断**  
**作用**：简化if-else，适合简单赋值  
**语法**：  
```c
变量 = (条件) ? 值1 : 值2;
```

**生活例子**：  
```c
int 分数 = 75;
char 结果 = (分数 >= 60) ? '✅' : '❌';
printf("%c", 结果); // 输出✅
```

**等价于**：  
```c
if(分数 >= 60) {
    结果 = '✅';
} else {
    结果 = '❌';
}
```

## 🚧 **避坑指南**  
1. **忘记大括号**：  
   ```c
   if(条件)
       printf("A");
       printf("B"); // 无论条件如何，B都会执行！
   // 正确写法：加{}
   ```

2. **switch穿透问题**：  
   ```c
   case 1: 
       printf("A");
       // 漏写break → 会继续执行case2的代码！
   case 2: ...
   ```

3. **浮点数判断**：  
   ```c
   float x = 0.1 + 0.2;
   if(x == 0.3) { ... } // ❌ 可能不成立！应改为范围判断
   ```
