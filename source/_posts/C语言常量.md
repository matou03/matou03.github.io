# 📌 **C语言常量——不可变的固定值**  
常量就像刻在石头上的数字🔢，一旦定义就不能修改。下面用最有趣的方式拆解常量知识！

---

## 一、**常量的种类**——不同口味的「固定饼干」🍪

### 1. **整数常量** 🔢  
**写法**：支持十进制、八进制、十六进制  
**生活类比**：  
- 十进制：日常计数（`100`）  
- 八进制：前导`0`（`0123` → 十进制的83）  
- 十六进制：前导`0x`（`0xFF` → 十进制的255）  

**示例**：  
```c
int a = 85;       // 十进制 → 85  
int b = 0213;     // 八进制 → 139  
int c = 0x4B;     // 十六进制 → 75  
```

**后缀小贴士**：  
- `L`或`l` → 长整型（`100L`）  
- `U`或`u` → 无符号（`30U`）  

---

### 2. **浮点常量** 🌊  
**写法**：小数或科学计数法  
**生活类比**：  
- 普通小数：`3.14`  
- 科学计数法：`2.5E3`（即2500.0）  

**示例**：  
```c
float pi = 3.14f;    // 加f表示float  
double big = 1.23e5; // 科学计数法 → 123000.0  
```

**常见错误**：  
```c
float x = 3.14;   // ❌ 默认是double，建议加f  
double y = 5E;    // ❌ 指数不完整  
```

---

### 3. **字符常量** 🔤  
**写法**：单引号包裹，支持转义符  
**生活类比**：  
- 普通字符：`'A'`  
- 转义字符：`'\n'`（换行）、`'\t'`（制表符）  

**示例**：  
```c
char newline = '\n';       // 换行符  
char tab = '\t';           // 制表符  
char backslash = '\\';     // 表示一个反斜杠  
```

**ASCII值转换**：  
```c
char c = 'a';  
int ascii = (int)c;   // 转为ASCII值97  
```

---

### 4. **字符串常量** 📜  
**写法**：双引号包裹，自动加`\0`结尾  
**生活类比**：  
- 字符串像火车🚂，每个字符是车厢，`\0`是终点标志  

**示例**：  
```c
char str[] = "Hello"; // 实际存储：H e l l o \0  
printf("你好\t世界\n"); // 输出带转义符的字符串  
```

**多行写法**：  
```c
char msg[] = "Hello "  
             "World!"; // 等同于"Hello World!"  
```

---

## 二、**定义常量的两种方式**——「替换贴纸」vs「只读标签」🏷️

### 1. **#define 预处理** ✨  
**特点**：  
- 简单文本替换（像代码里的贴纸）  
- 无类型检查  
- 作用域全局  

**示例**：  
```c
#define PI 3.14159  
#define GREETING "你好！"  

int main() {  
    double area = PI * 5 * 5;  
    printf("%s", GREETING);  
}  
```

**⚠️ 陷阱**：  
```c
#define MAX 100;  // ❌ 末尾不要加分号！  
int x = MAX * 2;  // 替换后变成 100; * 2 → 语法错误  
```

---

### 2. **const 关键字** 🔒  
**特点**：  
- 类型安全（编译器会检查）  
- 有作用域限制（像局部标签）  
- 实际占用内存  

**示例**：  
```c
const int MAX = 100;  
const float TAX = 0.1f;  

void func() {  
    const int LOCAL_CONST = 50; // 只在函数内有效  
}  
```

**常见错误**：  
```c
const int x;  
x = 10; // ❌ 必须定义时初始化！  
```

---

## 三、**define vs const 大比拼** 🥊

| **特性**       | **#define** ✨               | **const** 🔒               |  
|----------------|----------------------------|---------------------------|  
| **类型检查**   | ❌ 无                     | ✅ 有                    |  
| **作用域**     | 全局                       | 局部/全局                |  
| **内存占用**   | 无（文本替换）             | 有                       |  
| **调试**       | 难（替换后看不到原名）     | 易（保留变量名）         |  

**总结**：  
- 推荐多用`const`（更安全、易调试）  
- `#define`适合简单替换或跨文件常量

## 四、**实战避坑指南** 🚧

### 1. **转义字符错误**  
```c
printf("路径：C:\new\file.txt"); // ❌ 输出乱码！  
// 正确写法：  
printf("路径：C:\\new\\file.txt"); // ✅ 双反斜杠  
```

### 2. **字符串忘记\0**  
```c
char arr[4] = {'a','b','c','d'}; // ❌ 超出长度，无\0  
char str[] = "abcd";             // ✅ 自动补\0（长度5）  
```

### 3. **八进制数字错误**  
```c
int num = 089; // ❌ 八进制只能0~7！  
```

---

## 五、**常量的应用场景** 🎯

1. **固定配置**：  
   ```c
   #define MAX_USERS 1000  
   const int TIMEOUT = 30;  
   ```

2. **数学常数**：  
   ```c
   const double PI = 3.1415926535;  
   ```

3. **错误码定义**：  
   ```c
   #define ERROR_FILE_NOT_FOUND 404  
   ```

---

## 💡 **记忆口诀**  
> 常量不变值固定，类型不同用不同。  
> 整数浮点字符串，转义字符要记清。  
> 预处理或const选，安全类型选后者。  
> 八进制前加个0，十六进制0x明。
